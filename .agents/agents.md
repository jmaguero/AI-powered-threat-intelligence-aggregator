# Git and Commit Rules

You **MUST** follow these rules for git operations in this repository, no exceptions.

1. **Spotless Git Branches**: Follow a logical path for branching (e.g., separating features, fixes). Do not commit everything haphazardly.
2. **Clean Commits**: Make atomic, clean, and well-described commits.
3. **No Breaking Commits**: You are **NOT ALLOWED** to commit if there are errors or if the application does not build or run correctly. Always verify the app builds and runs correctly before making any commit.
4. **From Scratch**: We are curating the git repository from scratch. This means establishing a perfectly clean baseline and managing branches/commits immaculately from the ground up, discarding any previous messy history.
